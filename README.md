
# Sentinel
## This application currently is under heavy development
This applicaiton is currently under heavy development, and is intended to be used on Linux operating system. I'm planning to integrate it to windows very shortly, as the commits are constructed and pushed.

To compile this appliaction, I hope this will work:
```bash
bash ./simple_compile.sh
```

It requires ncurses to be installed from the repository. Furthermore other libraries will be used as well.

## General
Sentinel, for now (as it's going to change later) is C++ application designed to monitor the productivity, including standard discipline, and word-in-word writing code, measuring efficiency of the programming. (For now), it's designed for the old-classic programming style, as-if the AI is not implemented yet, and you're supposed to train programming through the coding means, and through writing the code yourself. I've designed it for the most part for myself, because I need application that's going to be counting lines of code, words, and efficiency of my programming, and showing me as the graph the efficiency of the programming, and the completeness of the tasks (another second feature of the statistics). This way I'm able to see my own efficiency. 

Currently the application uses ncurses in order to make it possible to edit code. But in the future I'm going to use different libraries, more oriented towards GUI (i.e. similar to Visual Code) 

### Background
My dreams **as a teenager** was to develop software that's going to be either fully sophisticated and combining multiple features at once... or to develop entire systems that are going to be developed from the bottom-up, entirely. For this purpose I've learned programming and software engineering, mainly, C++. What I missed though was the algorithms and mathematics. I always thought about training my own ability to write algorithms and train mathematics on my own. **This is from where the idea of the application came in.** 

We know currently that the programming requires expertiese, and in the current year there is a much anxiety regarding if the junior positions are replaced by the AI agents programming. This is already 2026. That's why I've decided that in order to develop one's own ability to code, one has to have efficiency-based programming environment which will contest the programming ability. The sentinel name corresponds to this theme, the "sentinel" name refers to the ability 'to protect one's own capabilities'. This means rehearsal, reinforcement, knowledge rehearsal, and especially - interactive training. But not in a sense of completing a course in order to get expertiese per-say. Or especially it doesn't mean using AI to generate code that one's oneself and others doesn't understand. This means acquiring the ability to develop on one's own, and through the true willingness to perservere. 

This application (as it's developed) will try to do that: Measure the programming efficiency, discipline tasks (basic stuff...), and in the future - connect with (to) many features that will allow to enhance one's own efficiency and programming. The main idea is that **training** equals **sentinel** -- The training itself; the deliberate practice is at the upmost importance.

I don't want to write this application using AI, and I don't want to write my other software pieces using AI. I also don't want to redact things in order to hide substance - such as this text itself. I want to remain as authentic as possible, and I don't want single sentence of text to be generated by AI. Not for the protectionalism sake, but for the sake of remaining steady. Just like the writers (from which I'm inspired), were massive generators of effort and output, I want to make the mission of programming fluent. Now I don't want to make the point that redaction is not important, it's more that I simply cannot stand AI output. I simply can't. I don't understand it, for the most part, and I need the touch of myself. The blueness and whiteness of the fonts and backgrounds in the visual code, of the text I'm typing and reading. And the long sentences I'm constructing. This is the spirit I'm developing this software.
